# 高频媒体风险规则 v3

版本：`media-risk-v3`；聚合字段版本：`aggregate-v3`。本模型是可解释的媒体监测指标，不以拟合年度榜单为目标，也不输出事件发生或企业亏损的概率。统计日期是官方15分钟导出批次的时间，代表媒体入库时间，不等同于事件发生日期。

## 公共规则

- Events提及权重`w=1+min(NumMentions,20)/10`，范围1–3，避免转载量直接支配结果。
- 样本支撑系数`R=n/(n+sample_prior)`，默认prior=20。页面evidence=100R，取一位小数后使用；Events的n是事件记录数，GKG的n是文档数。累计信源不当成独立样本再加一次。
- 风险响应`F(r)=100×r^power`，默认power=0.5、r限制在0–1。端点固定，连续单调；提升稀少负面信号的可见度，没有旧指数曲线的提前平台。幂次是透明的模型选择，尚未通过生产样本校准。
- 未采集点为空；低样本风险不排名，默认门槛20。R低时分数保守，不意味着现实安全。地图与排行同时查看样本及时间覆盖。
- 缺少必要Goldstein/AvgTone或GKG Tone的记录跳过并报告skipped_rows，不把缺失语调当作已测量的中性0；批次覆盖率不等于每条输入都可评分。

## 国家整体风险

输入为事件发生地点ActionGeoCountryCode。只统计负向Goldstein类别强度`g=max(0,-Goldstein/10)`，不把Goldstein当成伤亡或经济损失规模。

类别互斥：安全15/18/19/20（含军事姿态）；社会14/17；政治10/11/12/13/16。17不再重复计入社会和政治。分类本身是本系统的分析规则，CAMEO没有提供现成的“国家整体风险总分”。

各维度密度`r_j=Σ该维度(w×g)/Σ所有事件w`，分项分数`F(r_j)×R`。合作和非风险记录保留在分母，因此衡量报道事件构成中的负面压力，而非绝对危险事件数。

默认安全/社会/政治权重分别0.50/0.25/0.15。先合成事件强度：

```
I=(0.50*r安全+0.25*r社会+0.15*r政治)/max(0.50,0.25,0.15)
事件风险=F(I)*R
媒体风险=min(100,max(0,-平均语调)/8*100)*R
总分=0.90*事件风险+0.10*媒体风险
```

分项权重在密度阶段合成；总分不是展示分项分数的直接加权和。最大权重归一使“全部为最大强度安全冲突”的事件流可达事件分100，同时保留社会和政治的相对影响。权重变更会改变该参考情景，必须增加参数版本；默认权重不是实证估计。

Events语调沿用旧聚合：逐条截断到±10后平均，不是原始AvgTone均值。国家风险主要依靠类别强度，媒体仅占10%。新闻动量保留原完整日比较，用作活跃度提示，权重必须为0，不再给风险总分加分。

## 企业经营环境压力

输入为GKG报道，按报道提及的国家归属，同篇涉及多国分别计数。保留安全/政策/经济/基础设施/社会/健康六领域。

新增记录逐篇计算`u=max(0,min(1,-Tone/10))`。领域主题与负面语调必须在**同一篇报道**出现：`r_j=Σ(领域命中×u)/文档数`。正面贸易、能源建设或医疗报道单独出现不会增加领域风险；其他领域负面报道也不会和这篇正面报道错误配对。

分项`F(r_j)×R`，整体负面度`F(Σu/n)×R`。总分使用固定权重：安全24%、政策20%、经济20%、基础设施14%、社会12%、健康5%、整体负面度5%。不再使用国家横截面百分位；相同输入不因其他国家进入或退出排名而改变得分。

全文语调仍不能确认负面内容针对哪一个国家、哪一个主题或某一家企业；它是经营环境压力的代理指标，涉中企篇数单独展示，不等同于中资企业专属风险。

### 旧数据兼容

既有历史只保留主题篇数和语调之和，不能精确重建逐篇主题—负面联合密度。对旧记录估算`旧领域篇数×max(0,min(1,-旧平均语调/10))`，与新记录实测负面质量相加，再除全部文档数。

新旧分解使用专门保留的modeled_docs、sum_modeled_tone、各领域modeled_docs与negative统计，避免把新数据重复用于旧估算。

- `joint_method=measured`且`joint_coverage=100`：全部使用逐篇联合统计。
- `joint_method=legacy-estimate`：存在旧数据估算。
- `joint_coverage`：当前窗口参与实测的文档比例，不是采集覆盖率。

不能无声地把估算称为实测。随着监控持续运行，实时和近7/30天窗口逐渐达到全实测；长历史仍保留估算标记。本次不重新下载全部历史。如需要精确历史，应另行设计可回退的统计重建任务，不能直接清除done台账后重复累加。

## 对华整体倾向

仅使用Actor1为该国、Actor2为中国的跨国事件，不把“中国地名被提及”当成对华行为。

```
方向 = 0.70*(Goldstein/10) + 0.20*Quad方向 + 0.10*截尾Tone/10
Quad方向：口头合作+0.4、实质合作+1、口头冲突-0.4、实质冲突-1
倾向分 = 100 * Σ(w*方向)/Σw * R
```

负值表示冲突、正值表示合作、0为中性。该系数中Goldstein与Quad有相关性，并非独立信息；Quad补充行动方式，语调只作小比例辅助。少量事件向0收缩，不能把一次事件当成整个国家的明确立场。关系总览仍展示事件结构与合作/冲突数量，不是另一套态度分。

## 部署和历史重算

```bash
bash /opt/GDELTDataServer/deploy/update.sh
```

无需手动关闭监控。脚本停止服务、更新、测试、重启，监控/回填开关和台账保持。首次启动幂等增加GKG统计列，旧数据默认modeled_docs=0，不伪造历史实测。旧模型参数保存到数据库状态model_migration_backup；风险定义采用v3默认值，保留原对华配比、样本门槛与动量展示设置。已部署数据库的parameter_version增加1，snapshot_dirty置为真；重启不再次重置参数。

监控开启时后台会发布新快照；需要尽快切换可在当前任务收尾后点击“生成结果快照”。所有窗口及完整趋势在一个数据库读快照内按v3重算后原子发布，DSI下一次同步完整替换版本；新旧得分不拼接。保留上一份发布结果可回退。不要把旧快照改名假装v3。

DSI需识别model_version及企业joint_coverage，避免继续显示旧版“百分位”“动量占位参与总分”等说明。主页已有年度科研指数不随本次变更而重新计算。
